# Sheep Cérebro

O jeito de transformar o Claude Code em um agente pessoal com identidade, memória, autonomia e critério.

Isto não é o sistema Sheep nem um instalador. É o PRD do cérebro: como ele guarda contexto, decide sozinho, delega, verifica e protege os seus dados. O seu agente lê o documento e monta tudo com você, no seu computador.

O repositório não contém dados de nenhuma pessoa real.

## Como usar

Abra o Claude Code na pasta onde quer criar o seu agente e cole:

```text
Baixe https://github.com/marcusforti/sheep-cerebro com git clone e leia o PRD.md inteiro.
Implemente comigo fase por fase, seguindo a seção 10.
Na fase 2, faça a entrevista: pergunte uma coisa por vez e não invente nada sobre mim.
Antes de alterar ~/.claude/CLAUDE.md ou settings.json, mostre o que vai mudar e faça uma cópia de segurança.
No fim de cada fase, rode os testes da seção 11 e diga o que passou, o que falhou e o que não foi testado.
Não coloque chaves nem dados meus em arquivos versionados.
```

## O que tem aqui

- [`PRD.md`](PRD.md): requisitos, arquitetura, segurança, plano, critérios de aceite e modelos de arquivos.

## O que você precisa

- Claude Code instalado.
- Um computador com Windows, Mac ou Linux.
- Git, se for usar o comando acima.
